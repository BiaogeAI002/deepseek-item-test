main() 的 OSError 兜底可能误标「输出已关闭」

输出已移入 try 内执行，但 except OSError 覆盖整个 try：若命令层未来出现未包装的 OSError，会被误报为「输出已关闭」，掩盖真实 I/O 错误。当前 load_data/save_data 均已包装 OSError，实际不可达。
修复建议：把输出写入抽成 _emit(output) 并只在该函数内捕获 BrokenPipeError/OSError；命令层异常仍按层级包装。
def _emit(output: str) -> None:
    print(output)
    sys.stdout.flush()

UTF-8 BOM 文件被当作损坏

Windows 记事本手改保存可能带 BOM；decode("utf-8") 后 json.loads 报「不是合法 JSON」。数据不会被覆盖，但提示不够直观。
修复建议：读取时改用 utf-8-sig，或在错误文案中提示「文件带 BOM」。
text = raw_bytes.decode("utf-8-sig")
